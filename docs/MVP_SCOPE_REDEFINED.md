# MVP Scope Redefined

## Purpose

이 문서는 기능 회의 내용을 바탕으로 상세페이지 AI 제작 프로그램의 미니프로젝트 MVP 범위를 다시 정의합니다.

기존 MoSCoW의 Must Have는 사업화 수준의 기능까지 포함하고 있어, 수업 미니프로젝트에서 실제 완성 가능한 범위와 추후 확장 기능을 분리합니다.

## MVP Goal

상품 정보와 이미지를 입력하면 AI가 13개 섹션 기반 상세페이지 초안을 만들고, 사용자는 데스크톱에서 모바일 상세페이지 캔버스를 보며 블록 순서와 문구를 수정한 뒤, 플랫폼 업로드용 이미지 ZIP을 다운로드할 수 있습니다.

## One Line

AI가 상품 정보와 이미지를 바탕으로 13개 섹션 상세페이지를 자동 구성하고, 셀러가 데스크톱에서 블록형 캔버스로 수정한 뒤 플랫폼 업로드용 ZIP 이미지 패키지로 내보내는 미니프로젝트.

## MVP Must Have

### 1. 상품 정보 입력

필수 입력:

- 상품명
- 카테고리
- 핵심 키워드
- 타깃 고객
- 상품 이미지 업로드
- 톤앤매너 선택
- 디자인 무드 선택
- 강조 포인트 체크박스

입력 UI 원칙:

- 텍스트 입력은 최소화합니다.
- 카테고리, 톤, 무드, 강조 포인트는 선택형 UI로 받습니다.
- 사용자가 기획서를 쓰지 않아도 AI가 필요한 최소 정보를 확보하도록 설계합니다.

### 2. 업로드 이미지 자동 최적화

- 업로드 이미지 최대 가로폭: 1200px
- 출력 포맷: WebP 우선, 필요 시 JPEG
- 압축 품질: 0.85
- 원본 용량이 큰 경우 자동 압축
- 최적화 결과 표시

상태 표시 예시:

- "이미지를 최적화했습니다."
- "8.4MB -> 1.2MB"
- "가로 3024px -> 1200px"

### 3. 13대 섹션 기반 AI 카피 생성

- 13개 고정 섹션 구조를 사용합니다.
- 섹션별 제목, 본문, 대체 카피를 생성합니다.
- AI 출력은 JSON 스키마 기반으로 통제합니다.
- temperature는 낮게 설정해 사실 왜곡을 줄입니다.
- 사용자가 제공하지 않은 성능, 인증, 효과, 수치 정보는 생성하지 않도록 규칙을 둡니다.

13개 섹션:

1. Intro
2. One Line Selling Point
3. Problem
4. Solution
5. Key Benefit 1
6. Key Benefit 2
7. Key Benefit 3
8. Detail Point
9. Use Scene
10. Recommended For
11. Trust Point
12. FAQ
13. CTA

### 4. 무드 프리셋 기반 레이아웃 자동 매칭

- Pinterest API는 MVP에서 연동하지 않습니다.
- 내부 무드 프리셋으로 레이아웃을 자동 적용합니다.
- 사용자가 선택한 카테고리, 디자인 무드, 강조 방식에 따라 13개 섹션의 블록 타입을 자동 배정합니다.

MVP 프리셋 후보:

- 미니멀
- 감성
- 프리미엄
- 정보형
- 공구형

### 5. 데스크톱 기반 모바일 상세페이지 캔버스

- 사용자는 PC/노트북에서 서비스를 사용합니다.
- 캔버스는 모바일 상세페이지 결과물 비율로 보여줍니다.
- 실제 출력은 플랫폼 가로폭 기준으로 생성합니다.
- 화면 표시용 축소 캔버스와 출력용 캔버스 개념을 구분합니다.

### 6. 블록형 편집

사용자가 할 수 있는 일:

- 섹션 순서 변경
- 섹션 문구 수정
- 섹션 숨김/삭제
- 이미지 교체
- 추천 카피 후보 선택

MVP에서 하지 않는 일:

- 자유 좌표 배치
- 텍스트 박스 임의 생성
- 이미지 레이어 세밀 조정
- 피그마/캔바식 리사이즈 편집

### 7. 플랫폼 업로드용 이미지 패키지 다운로드

- 에이블리 860px 지원
- 지그재그 1000px 지원
- 상세페이지를 2000px 단위로 슬라이싱합니다.
- `01.png`, `02.png`, `03.png`처럼 파일명을 자동 정리합니다.
- 잘린 이미지들을 ZIP으로 묶어 다운로드합니다.

## MVP Should Have

- 섹션별 대체 카피 선택
- 톤앤매너 재생성
- 전체 PNG 1장 다운로드 옵션
- 섹션별 슬라이싱 옵션
- 미리보기 확대/축소
- 샘플 상품 데이터 불러오기
- 생성 결과 임시 저장

## MVP Could Have

- dnd-kit 기반 부드러운 드래그 앤 드롭
- 브랜드 컬러 간단 선택
- 고화질 이미지 최적화 옵션
- 1500/2000/3000px 슬라이싱 단위 선택
- 스마트스토어/쿠팡 가로폭 프리셋 추가
- FAQ만 다시 생성
- 특정 섹션만 다시 생성

## MVP Won't Have

- Pinterest API 실시간 연동
- 레퍼런스 이미지 분석
- 상품 이미지 누끼 제거
- Image-to-Image 합성
- 이미지 복잡도 기반 텍스트 안전영역 자동 배치
- 피그마식 자유 편집
- 쇼핑몰 플랫폼 직접 업로드
- 로그인/결제
- 대량 상품 일괄 생성
- Electron/Tauri 데스크톱 앱

## Realistic Implementation Order

1. 13개 섹션 데이터 구조 정의
2. 샘플 상품/mock JSON으로 모바일 캔버스 구현
3. 상품 입력 폼 구현
4. 이미지 업로드 및 자동 최적화 구현
5. 무드 프리셋/블록 템플릿 구현
6. 텍스트 수정, 섹션 숨김, 순서 변경 구현
7. AI 카피 생성 API 연결
8. 플랫폼 가로폭 선택 구현
9. PNG 생성 구현
10. 2000px 슬라이싱 및 ZIP 다운로드 구현

## Implementation Difficulty Notes

이미 경험이 있는 범위:

- Next.js 기반 웹앱 구성
- TypeScript 데이터 구조 설계
- Tailwind 기반 UI 구현
- API route 구성
- Gemini/Claude 등 AI API 연동
- 파일 export 경험

이번 프로젝트에서 새롭게 도전해야 하는 범위:

- 캔버스/DOM 기반 이미지 생성
- 업로드 이미지 클라이언트 최적화
- 상세페이지 긴 이미지 슬라이싱
- ZIP 패키징 다운로드
- dnd-kit 기반 섹션 블록 재정렬

따라서 구현 순서는 UI와 데이터 구조를 먼저 안정화하고, 이미지 export/ZIP 기능은 후반에 붙이는 방식이 적합합니다.
