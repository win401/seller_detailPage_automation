# Project Brief

## Project Name

Seller Detail Page Automation

## Korean Name Candidates

- 상세페이지 자동 제작 도구
- 셀러페이지 AI
- 상세페이지 메이커
- 셀러 상세페이지 코치

## One Line

쿠팡, 스마트스토어 셀러가 상품 정보와 사진만 입력하면 AI가 상세페이지 문구, 구성, 디자인 초안을 자동으로 만들어주는 제작 자동화 툴.

## Background

온라인 셀러에게 상세페이지는 구매 전환에 직접 영향을 주는 핵심 콘텐츠입니다. 하지만 초보 셀러와 소상공인은 상세페이지 제작에 필요한 카피라이팅, 디자인 구성, 이미지 배치, 플랫폼별 형식 이해가 부족한 경우가 많습니다.

이 프로젝트는 상세페이지 제작 과정을 AI 기반 워크플로우로 단순화합니다. 사용자는 상품 정보와 사진을 넣고, AI는 판매 문구와 상세페이지 구조를 생성하며, 디자인 도구는 시각적 레이아웃 초안을 만들어줍니다.

## Target Users

- 쿠팡 셀러
- 네이버 스마트스토어 셀러
- 1인 쇼핑몰 운영자
- 위탁판매/사입 판매자
- 상세페이지 제작 외주비가 부담되는 초보 셀러
- 디자인 툴 사용이 어려운 소상공인

## Problems

- 상세페이지 제작 외주 비용이 부담됩니다.
- 직접 만들려면 디자인 툴 사용법을 배워야 합니다.
- 상품 특징을 구매 설득 문구로 바꾸기 어렵습니다.
- 어떤 섹션 순서로 구성해야 하는지 알기 어렵습니다.
- 상세페이지를 만들 때마다 반복 작업이 많습니다.

## Solution

상품 정보와 사진을 입력하면 AI가 다음 결과물을 생성합니다.

- 상품 상세페이지 제목
- 메인 카피
- 핵심 장점 3-5개
- 상세 설명 섹션
- 사용 시나리오
- FAQ
- 구매 유도 문구
- 상세페이지 디자인 초안
- 플랫폼 업로드용 이미지 또는 HTML 결과물

## Differentiation

단순 문구 생성기가 아니라, 상세페이지 제작 흐름 전체를 자동화합니다.

- 입력: 상품 정보, 이미지, 타깃 고객
- 생성: 카피, 섹션 구성, 디자인 초안
- 수정: 미리보기에서 직접 편집
- 출력: 이미지/HTML/복사용 텍스트

## Demo Goal

발표 시에는 셀러가 상품 정보를 입력하고 버튼을 누르면, 상세페이지 초안이 생성되어 미리보기와 다운로드까지 이어지는 흐름을 보여줍니다.
