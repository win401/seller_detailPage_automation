# Project Brief

## 프로젝트명

Seller Detail Page Automation

## 한 줄 설명

상품 정보, 이미지, 경쟁 상세페이지 URL/메모를 입력하면 여러 AI 에이전트가 분석, 기획, 제작, 검수를 단계별로 수행하고, 사용자가 블록형 캔버스에서 수정한 뒤 플랫폼 업로드용 이미지 ZIP을 다운로드하는 웹 애플리케이션입니다.

## 문제 정의

초보 셀러는 상세페이지를 만들 때 다음 문제를 겪습니다.

- 상품 장점을 어떤 순서로 보여줘야 하는지 어렵습니다.
- 모바일에서 읽기 좋은 문구를 작성하기 어렵습니다.
- 디자인 툴 사용이 부담스럽습니다.
- 도매꾹 같은 도매 사이트에서 가져온 상품 이미지는 상세페이지에 바로 쓰기에는 퀄리티가 낮은 경우가 많습니다.
- 경쟁 셀러의 상세페이지를 참고하고 싶지만 어떤 포인트를 분석해야 하는지 막막합니다.
- AI가 바로 문구를 생성해도 전략, 구성, 검수 과정이 없으면 결과물이 가볍게 느껴질 수 있습니다.
- 플랫폼별 이미지 규격과 슬라이싱 작업이 번거롭습니다.
- 반복적으로 비슷한 톤앤매너를 다시 설정해야 합니다.
- 세로로 긴 상세페이지를 작업해야 해서 일반 가로 모니터뿐 아니라 세로 모니터에서도 편하게 볼 수 있어야 합니다.
- 장시간 작업하는 도구이므로 light/dark 모드를 지원해 작업 피로도를 줄여야 합니다.

## 해결 방향

이 프로젝트는 상세페이지 제작 과정을 에이전트 기반 워크플로우로 단순화합니다.

1. 상품 정보와 추가 제작 요청 입력
2. 이미지 업로드
3. 경쟁 상세페이지 URL/메모 입력
4. 분석 에이전트가 사용자가 제공한 URL/메모와 상품 정보를 바탕으로 경쟁 포인트를 정리
5. 기획 에이전트가 섹션 전략, 타깃, 톤앤매너, 이미지 방향을 설계
6. 제작 에이전트가 13섹션 상세페이지 초안을 생성
7. 검수 에이전트가 과장 표현, 근거 없는 수치/인증, 누락 섹션, 모바일 가독성을 점검
8. 모바일 상세페이지 캔버스 미리보기
9. 블록 단위 문구/순서 수정
10. AI 편집 도우미로 선택 섹션을 빠르게 수정
11. 사용자 수정 이력과 스타일 선호를 저장
12. 프로젝트 저장
13. 플랫폼 업로드용 ZIP 다운로드

편집기는 데스크톱 웹 앱을 기준으로 만들되, 가로 모니터와 세로 모니터 모두에서 작업하기 좋은 반응형 레이아웃을 제공합니다.

앱 UI는 light/dark 모드를 지원하되, 상세페이지 캔버스의 최종 export 디자인은 사용자의 앱 테마와 분리해서 유지합니다.

## 성공 기준

데모에서 사용자가 상품 정보를 입력하고 AI 상세페이지 초안을 생성한 뒤, 캔버스에서 수정하고 ZIP 파일로 다운로드하는 전체 흐름을 보여줄 수 있어야 합니다.

AI 편집 도우미는 사용자가 직접 모든 문구를 수정하지 않아도 선택한 섹션을 다시 쓰거나, 과장 표현을 줄이거나, FAQ/CTA를 빠르게 개선할 수 있게 돕습니다. 현재 버전에서는 상세페이지 편집기 안의 보조 패널로 제공하고, 앱 전체를 조작하는 범용 챗봇으로 만들지는 않습니다.

경쟁 분석은 실제 자동 크롤링이 아니라 사용자가 입력한 경쟁 상세페이지 URL, 참고 메모, 캡처/요약 정보를 바탕으로 시작합니다. MVP에서는 법적/기술적 리스크를 줄이기 위해 외부 사이트를 자동으로 긁어오지 않고, URL은 참고 출처와 분석 맥락을 관리하는 입력값으로 사용합니다.

이미지 개선 기능은 원본 상품 이미지를 무작정 새로 만드는 기능이 아니라, 사용자가 업로드한 상품 이미지와 레퍼런스 이미지를 기준으로 상세페이지에 어울리는 배경, 조명, 구도, 분위기를 제안하고 개선 결과를 캔버스에 반영하는 흐름으로 설계합니다. 실제 상품의 형태, 색상, 소재, 구성품은 사용자가 제공한 정보에서 벗어나지 않아야 합니다.
