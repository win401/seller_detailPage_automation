# Project Brief

## 프로젝트명

Seller Detail Page Automation

## 한 줄 설명

상품 정보와 이미지를 입력하면 AI가 상세페이지 초안을 만들고, 사용자가 블록형 캔버스에서 수정한 뒤 플랫폼 업로드용 이미지 ZIP을 다운로드하는 웹 애플리케이션입니다.

## 문제 정의

초보 셀러는 상세페이지를 만들 때 다음 문제를 겪습니다.

- 상품 장점을 어떤 순서로 보여줘야 하는지 어렵습니다.
- 모바일에서 읽기 좋은 문구를 작성하기 어렵습니다.
- 디자인 툴 사용이 부담스럽습니다.
- 플랫폼별 이미지 규격과 슬라이싱 작업이 번거롭습니다.
- 반복적으로 비슷한 톤앤매너를 다시 설정해야 합니다.

## 해결 방향

이 프로젝트는 상세페이지 제작 과정을 다음 흐름으로 단순화합니다.

1. 상품 정보 입력
2. 이미지 업로드
3. AI 13섹션 상세페이지 초안 생성
4. 모바일 상세페이지 캔버스 미리보기
5. 블록 단위 문구/순서 수정
6. 프로젝트 저장
7. 플랫폼 업로드용 ZIP 다운로드

## 핵심 기능

- 이메일 로그인/회원가입
- 상품 정보 입력 폼
- 이미지 업로드 및 자동 최적화
- AI 기반 상세페이지 문구 생성
- 13개 섹션 구조
- 모바일 상세페이지 캔버스
- 섹션 블록 편집
- 사용자별 스타일 세트 저장
- Supabase 프로젝트 저장
- 플랫폼별 이미지 슬라이싱 ZIP 다운로드
- 기본 관리자 화면

## 제외 범위

- 쇼핑몰 직접 업로드
- 결제
- 팀 협업
- Pinterest API 연동
- AI 이미지 합성
- AI 누끼 제거
- 피그마식 자유 편집
- 대량 상품 일괄 생성

## 주요 기술

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase
- Vercel AI SDK
- zod
- dnd-kit
- JSZip

## 성공 기준

데모에서 사용자가 상품 정보를 입력하고 AI 상세페이지 초안을 생성한 뒤, 캔버스에서 수정하고 ZIP 파일로 다운로드하는 전체 흐름을 보여줄 수 있어야 합니다.
