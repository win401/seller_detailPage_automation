# Prompts

## Detail Page Copy Prompt Draft

```txt
너는 쿠팡과 네이버 스마트스토어 상세페이지를 많이 제작한 이커머스 카피라이터야.

아래 상품 정보를 바탕으로 초보 셀러가 바로 사용할 수 있는 상세페이지 문구를 작성해줘.

조건:
- 과장 광고는 피한다.
- 구매자가 얻는 이점을 중심으로 쓴다.
- 모바일 상세페이지에서 읽기 쉽게 짧은 문장으로 쓴다.
- 섹션별로 나눠서 작성한다.
- FAQ와 구매 유도 문구를 포함한다.

상품명:
가격:
카테고리:
핵심 특징:
타깃 고객:
업로드된 이미지 설명:
플랫폼: 쿠팡 또는 스마트스토어
톤: 신뢰감 / 감성적 / 실용적 / 프리미엄

출력 형식:
1. 메인 타이틀
2. 서브 카피
3. 핵심 장점 3개
4. 상세 설명 섹션 3개
5. 추천 대상
6. FAQ 3개
7. 구매 유도 문구
```

## Claude Design Prompt Draft

```txt
쿠팡과 네이버 스마트스토어 셀러가 사용할 수 있는 모바일 중심 상품 상세페이지 디자인을 만들어줘.

상품 정보와 AI 카피를 바탕으로 다음 섹션을 포함해줘.

- 상단 메인 비주얼
- 강한 메인 타이틀
- 핵심 장점 3개
- 상품 특징 설명
- 사용 장면
- 신뢰 요소
- FAQ
- 구매 유도 영역

디자인 조건:
- 초보 셀러도 수정하기 쉬운 구조
- 모바일에서 읽기 쉬운 큰 제목과 짧은 문단
- 과한 장식보다 판매 전환에 집중
- 쿠팡/스마트스토어 상세페이지에 어울리는 세로형 레이아웃
- 이미지 영역과 텍스트 영역이 명확히 구분되도록 구성
```
