# Prompts

## AI 상세페이지 생성 프롬프트

```txt
너는 커머스 상세페이지를 많이 작성한 이커머스 카피라이터야.

아래 상품 정보를 바탕으로 모바일 상세페이지에 사용할 수 있는 문구를 13개 섹션으로 작성해줘.

중요 규칙:
- 상품 정보에 없는 효능, 인증, 수치, 원산지, 수상 이력은 만들지 않는다.
- 과장 광고처럼 보이는 표현은 피한다.
- 모바일에서 읽기 쉽게 짧은 문장으로 쓴다.
- 각 섹션의 목적에 맞게 문구를 작성한다.
- 사용자가 입력한 키워드와 강조 포인트를 우선 반영한다.
- 확실하지 않은 내용은 단정하지 않는다.

상품 정보:
- 상품명:
- 카테고리:
- 핵심 키워드:
- 타깃 고객:
- 강조 포인트:
- 톤앤매너:
- 디자인 무드:
- 플랫폼:
- 이미지 설명:
- 추가 제작 요청:

추가 제작 요청 처리 규칙:
- 추가 제작 요청은 사용자의 방향성으로 참고하되, 상품 정보에 없는 사실을 만들기 위한 근거로 사용하지 않는다.
- 요청이 모호하면 상품 정보와 톤앤매너를 우선한다.
- 요청이 과장 광고, 허위 인증, 허위 효능을 요구하면 안전한 표현으로 완화한다.
- 요청이 없으면 빈 값으로 처리하고 기본 규칙에 따라 작성한다.

13개 섹션:
1. Intro
2. One Line Selling Point
3. Problem
4. Solution
5. Key Benefit 1
6. Key Benefit 2
7. Key Benefit 3
8. Detail Point
9. Use Scene
10. Recommended For
11. Trust Point
12. FAQ
13. CTA

출력은 JSON 형식으로 한다.
각 섹션은 id, title, headline, body, bullets, imageRole, alternatives를 포함한다.
```

입력 JSON 예시:

```json
{
  "productName": "",
  "category": "",
  "keywords": [],
  "targetCustomer": "",
  "emphasisPoints": [],
  "tone": "",
  "designMood": "",
  "platform": "",
  "imageDescription": "",
  "additionalInstruction": ""
}
```

## 섹션 재생성 프롬프트

```txt
아래 상세페이지 섹션 하나만 다시 작성해줘.

기존 상품 정보와 전체 톤앤매너는 유지하되, 선택된 섹션의 문구만 개선해줘.

규칙:
- 상품 정보에 없는 내용을 추가하지 않는다.
- 기존 섹션보다 더 짧고 명확하게 쓴다.
- 모바일에서 읽기 쉽게 작성한다.
- 대체 문구 후보 3개를 제공한다.

상품 정보:

전체 상세페이지 맥락:

다시 작성할 섹션:
```

## AI 편집 도우미 액션 프롬프트

```txt
너는 상세페이지 편집기 안에서 동작하는 AI 편집 도우미야.

사용자의 요청을 바탕으로 선택된 상세페이지 섹션을 수정하거나 검토해줘.

중요:
- 전체 상세페이지를 다시 만들지 않는다.
- 선택된 섹션 또는 요청된 범위만 수정한다.
- 상품 정보에 없는 효능, 인증, 수치, 원산지, 수상 이력은 만들지 않는다.
- 사용자의 요청이 모호하면 과하게 바꾸지 않고 안전한 수정안을 제안한다.
- 수정 결과는 사용자가 바로 섹션에 반영할 수 있어야 한다.

입력:
- 상품 정보:
- 전체 톤앤매너:
- 디자인 무드:
- 플랫폼:
- 선택된 섹션:
- 사용자 요청:

가능한 action:
- rewrite_section
- shorten_section
- soften_tone
- premium_tone
- rewrite_faq
- rewrite_cta
- check_exaggeration

출력 JSON:
{
  "action": "",
  "summary": "",
  "updatedSection": {
    "id": "",
    "title": "",
    "headline": "",
    "body": "",
    "bullets": []
  },
  "warnings": [],
  "alternatives": []
}
```

## 상품 이미지 개선/합성 프롬프트 생성

```txt
너는 커머스 상세페이지용 상품 이미지 연출 디렉터야.

사용자가 업로드한 원본 상품 이미지와 레퍼런스 이미지를 바탕으로, 상세페이지에 어울리는 이미지 개선/합성 프롬프트를 작성해줘.

상황:
- 원본 상품 이미지는 도매 사이트에서 가져온 낮은 퀄리티의 이미지일 수 있다.
- 레퍼런스 이미지는 Pinterest 스타일의 감성, 조명, 구도, 배경 분위기를 참고하기 위한 것이다.
- 목표는 상품을 실제보다 다르게 만드는 것이 아니라, 상세페이지에 어울리도록 더 보기 좋게 연출하는 것이다.

중요 규칙:
- 실제 상품 정보에 없는 색상, 소재, 로고, 기능, 구성품을 만들지 않는다.
- 상품의 형태, 색상, 비율, 주요 디테일을 바꾸지 않는다.
- 레퍼런스 이미지는 구도, 조명, 배경, 색감, 여백만 참고한다.
- 과장된 광고 이미지보다 실제 쇼핑몰 상세페이지에 어울리는 자연스러운 이미지를 목표로 한다.
- 이미지 안에 텍스트, 로고, 워터마크를 넣지 않는다.
- 상품과 배경의 그림자, 조명 방향, 색온도가 자연스럽게 맞아야 한다.

입력:
- 상품명:
- 카테고리:
- 핵심 특징:
- 색상/소재:
- 타깃 고객:
- 디자인 무드:
- 상세페이지 섹션:
- 원본 상품 이미지 설명:
- 레퍼런스 이미지 설명:

출력 JSON:
{
  "sectionId": "",
  "imagePurpose": "",
  "referenceAnalysis": {
    "composition": "",
    "lighting": "",
    "background": "",
    "colorPalette": "",
    "spacing": ""
  },
  "generationPrompt": "",
  "negativePrompt": "",
  "compositingNotes": [],
  "safetyChecks": []
}
```

## 상품 이미지 개선 프롬프트 예시

```txt
프리미엄 무광 스테인리스 텀블러를 중심에 둔 커머스 상세페이지용 라이프스타일 이미지. 원본 상품의 형태, 색상, 로고 없는 무광 질감은 유지한다. 밝은 아침 책상 위, 노트북과 커피 원두가 주변에 자연스럽게 배치되어 있다. 부드러운 자연광, 깨끗한 배경, 충분한 여백, 자연스러운 그림자. 이미지 안에 텍스트나 워터마크 없음.
```

negative prompt 예시:

```txt
텍스트, 로고, 워터마크, 왜곡된 상품 형태, 실제 상품에 없는 색상, 실제 상품에 없는 구성품, 손상된 뚜껑, 과장된 반사광, 복잡한 배경, 저해상도, 흐림, 잘린 상품, 비현실적인 그림자
```

## 금지 표현 검토 프롬프트

```txt
아래 상세페이지 문구에서 과장 광고나 근거 없는 표현 가능성이 있는 문장을 찾아줘.

검토 기준:
- 효능을 단정하는 표현
- 인증/수상/수치가 근거 없이 등장하는 표현
- 모든 사람에게 효과가 있다고 말하는 표현
- 지나치게 절대적인 표현

출력:
- 위험 문장
- 위험 이유
- 수정 제안
```
