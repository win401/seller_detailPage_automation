# Claude Design Prompt

## 사용 목적

이 문서는 Claude Design으로 상세페이지 AI 제작 프로그램의 UI/UX 초안을 만들기 위한 프롬프트입니다.

Claude Design에는 GitHub repo를 연결한 뒤, 아래 프롬프트를 함께 입력합니다.

연결 repo:

```txt
https://github.com/win401/seller_detailPage_automation.git
```

## 핵심 요청 프롬프트

```txt
너는 SaaS 프로덕트 UI/UX 디자이너이자 프론트엔드 설계자야.

아래 GitHub repo를 참고해서, 현재 Next.js + TypeScript + Tailwind CSS + shadcn/ui 기반 프로젝트 구조에 맞는 UI/UX 초안을 만들어줘.

Repo:
https://github.com/win401/seller_detailPage_automation.git

서비스 개요:
이 서비스는 쿠팡, 네이버 스마트스토어, 에이블리, 지그재그 같은 커머스 플랫폼에 상품을 판매하는 셀러를 위한 AI 상세페이지 제작 도구야.
셀러가 상품 정보와 이미지를 입력하면 AI가 13개 섹션 기반 상세페이지 문구와 구성 초안을 만들고, 사용자는 PC/노트북에서 모바일 상세페이지 캔버스를 보며 블록 단위로 수정한 뒤, 플랫폼 업로드용 이미지 ZIP을 다운로드할 수 있어.

중요:
이 서비스는 모바일 앱이 아니야.
사용자는 데스크톱에서 작업하지만, 결과물 미리보기는 모바일 상세페이지 형태의 긴 세로 캔버스로 보여줘야 해.

제품 포지셔닝:
- 피그마/캔바 같은 자유 디자인 툴이 아님
- 초보 셀러가 빠르게 상세페이지 초안을 만들 수 있는 AI 제작 자동화 툴
- 섹션 블록 단위로만 편집하는 구조
- 완성도 높은 결과물을 빠르게 얻는 것이 핵심

디자인 톤:
- 실무형 SaaS 대시보드
- 조용하고 전문적인 분위기
- 셀러가 반복 작업하기 좋은 밀도
- 과한 랜딩페이지 느낌 금지
- 카드가 너무 많고 장식적인 마케팅 페이지 느낌 금지
- 한 화면에서 입력, 미리보기, 편집 상태를 빠르게 파악할 수 있어야 함

기술 제약:
- Next.js App Router 기준
- TypeScript 사용
- Tailwind CSS 사용
- shadcn/ui 컴포넌트 사용
- lucide-react 아이콘 사용
- dnd-kit으로 섹션 순서 변경 예정
- Supabase Auth/DB/Storage 연동 예정
- Vercel AI SDK로 AI 생성 API 연동 예정
- JSZip과 DOM/canvas capture로 이미지 export 예정

디자인할 핵심 화면:

1. 로그인/회원가입 화면
2. 프로젝트 대시보드 화면
3. 새 상세페이지 생성 화면
4. 상세페이지 편집기 화면
5. 스타일 세트 관리 화면
6. 관리자 대시보드 화면

각 화면의 목적과 구성은 아래 내용을 따라줘.
```

## 화면별 상세 요구사항

### 1. 로그인/회원가입 화면

```txt
로그인/회원가입 화면을 디자인해줘.

목적:
셀러가 이메일/비밀번호로 빠르게 가입하고 작업 공간으로 진입한다.

필수 요소:
- 서비스명 영역
- 짧은 가치 제안 문구
- 이메일 입력
- 비밀번호 입력
- 로그인 버튼
- 회원가입 전환 링크
- 데모 계정으로 시작하기 버튼 또는 링크

디자인 방향:
- 화려한 랜딩페이지가 아니라 SaaS 진입 화면
- 왼쪽에는 제품 가치, 오른쪽에는 폼을 두는 구성이 가능함
- 단, 과한 일러스트나 추상 그래픽은 피함
- 셀러가 바로 업무 도구에 들어가는 느낌
```

### 2. 프로젝트 대시보드 화면

```txt
프로젝트 대시보드 화면을 디자인해줘.

목적:
사용자가 저장된 상세페이지 프로젝트를 확인하고 새 프로젝트를 시작한다.

필수 요소:
- 상단 네비게이션
- 새 상세페이지 만들기 버튼
- 프로젝트 검색
- 프로젝트 상태 필터
- 최근 프로젝트 리스트
- 프로젝트 카드 또는 테이블
- 각 프로젝트의 상품명, 카테고리, 플랫폼, 수정일, 완성도 점수 표시
- 스타일 세트 바로가기

디자인 방향:
- 실제 SaaS 작업 대시보드처럼 보이게
- 프로젝트가 많아져도 관리하기 쉬운 밀도
- 카드형만 고집하지 말고 테이블/리스트 혼합 가능
- 초보 셀러가 다음 행동을 쉽게 알 수 있어야 함
```

### 3. 새 상세페이지 생성 화면

```txt
새 상세페이지 생성 화면을 디자인해줘.

목적:
셀러가 AI 생성에 필요한 정보를 부담 없이 입력한다.

필수 입력:
- 상품명
- 카테고리
- 핵심 키워드
- 타깃 고객
- 상품 이미지 업로드
- 톤앤매너 선택
- 디자인 무드 선택
- 강조 포인트 체크박스
- 플랫폼 선택
- 저장된 스타일 세트 선택

UI 요구:
- 모든 것을 텍스트 입력으로 만들지 말 것
- 카테고리, 톤앤매너, 디자인 무드, 강조 포인트는 선택형 UI 사용
- 강조 포인트는 체크박스 또는 토글 칩 사용
- 이미지 업로드 영역에는 최적화 상태를 표시
- 예: "이미지를 최적화했습니다. 8.4MB -> 1.2MB"
- AI 생성 버튼은 명확하게 강조

디자인 방향:
- 폼이 길어도 부담스럽지 않게 단계나 섹션으로 나눔
- 좌측 입력, 우측 생성 요약/미리보기 형태도 가능
- 사용자가 "필요한 정보만 넣으면 된다"고 느껴야 함
```

### 4. 상세페이지 편집기 화면

```txt
상세페이지 편집기 화면을 가장 중요하게 디자인해줘.

목적:
AI가 생성한 상세페이지를 사용자가 블록 단위로 수정하고, 모바일 상세페이지 결과물을 확인한다.

핵심 레이아웃:
- 데스크톱 작업 화면
- 중앙 또는 좌측에 모바일 상세페이지 캔버스
- 한쪽에는 섹션 목록/편집 패널
- 상단에는 저장, 미리보기, 플랫폼 선택, export 버튼

모바일 캔버스:
- 결과물은 모바일 쇼핑 상세페이지처럼 긴 세로형
- 실제 모바일 기기 프레임처럼 보일 수 있음
- 13개 섹션이 순서대로 표시됨
- 각 섹션은 이미지/제목/본문/CTA 등의 블록으로 구성
- 선택된 섹션은 명확하게 표시

13개 섹션:
1. Intro
2. One Line Selling Point
3. Problem
4. Solution
5. Key Benefit 1
6. Key Benefit 2
7. Key Benefit 3
8. Detail Point
9. Use Scene
10. Recommended For
11. Trust Point
12. FAQ
13. CTA

편집 기능:
- 섹션 문구 수정
- 섹션 이미지 교체
- 섹션 숨김/복구
- 추천 카피 후보 선택
- dnd-kit 기반 섹션 순서 변경
- 특정 섹션만 AI 재생성

제공하지 않는 기능:
- 피그마식 자유 좌표 배치
- 텍스트 박스 임의 생성
- 레이어 패널
- 이미지 세밀 리사이즈
- 복잡한 자유 드로잉 도구

UI 요구:
- 사용자가 자유 편집 툴이 아니라 블록형 AI 편집기라고 느껴야 함
- 섹션 순서 변경은 드래그 핸들 아이콘으로 표현
- 섹션 숨김은 eye/eye-off 아이콘 사용
- 섹션 재생성은 sparkle/refresh 아이콘 사용
- 텍스트 수정은 선택된 섹션의 패널에서 진행
- 버튼에는 lucide-react 아이콘을 적극 활용

Export 영역:
- 플랫폼 선택: 에이블리 860px, 지그재그 1000px, 스마트스토어, 쿠팡
- 전체 PNG 다운로드
- 2000px 단위 슬라이싱 ZIP 다운로드
- 다운로드 전 예상 파일 개수 표시

디자인 방향:
- 이 화면이 제품의 핵심임
- 전문적인 에디터처럼 보이되, 피그마처럼 복잡하면 안 됨
- 셀러가 "외부 디자인 툴 없이 여기서 끝낼 수 있겠다"고 느껴야 함
```

### 5. 스타일 세트 관리 화면

```txt
스타일 세트 관리 화면을 디자인해줘.

목적:
셀러가 자주 쓰는 상세페이지 톤앤매너와 브랜드 스타일을 저장한다.

필수 요소:
- 스타일 세트 목록
- 새 스타일 세트 만들기
- 스타일 세트 이름
- 기본 디자인 무드
- 기본 톤앤매너
- 대표 색상
- 보조 색상
- 폰트 분위기
- 기본 플랫폼 규격
- 강조 포인트 기본값
- 섹션 표시/숨김 기본값
- 브랜드/스토어 메모

디자인 방향:
- 브랜드 키트처럼 보이되 너무 복잡하지 않게
- 색상은 swatch UI 사용
- 무드/톤은 segmented control 또는 select 사용
- 섹션 표시 여부는 토글 리스트 사용
```

### 6. 관리자 대시보드 화면

```txt
관리자 대시보드 화면을 디자인해줘.

목적:
운영자가 서비스 사용 흐름과 데이터 인사이트를 확인한다.

중요:
관리자 대시보드는 개별 셀러의 민감한 상품 정보를 보여주는 화면이 아님.
익명/집계 데이터를 중심으로 보여줘야 함.

필수 지표:
- 전체 가입자 수
- 전체 프로젝트 수
- AI 생성 횟수
- ZIP 다운로드 횟수
- 인기 상품 카테고리
- 인기 디자인 무드
- 인기 톤앤매너
- 플랫폼 선택 분포
- 자주 수정되는 섹션
- 자주 숨겨지는 섹션
- 스타일 세트 사용 빈도
- 최근 프로젝트 메타데이터

UI 구성:
- 상단 KPI 카드
- 카테고리/무드/플랫폼 차트
- 섹션 수정/숨김 빈도 리스트
- 최근 이벤트 테이블
- 기간 필터

디자인 방향:
- SaaS 운영자 화면처럼 차분하고 정보 밀도가 있어야 함
- 과한 색상보다 읽기 쉬운 운영 대시보드
- 개별 상품 원문을 노출하지 않는 구조
```

## 디자인 시스템 요구사항

```txt
전체 디자인 시스템을 다음 기준으로 잡아줘.

스타일:
- 모던 SaaS
- 이커머스 셀러 도구
- 차분하고 전문적
- 반복 사용에 피로감이 적은 UI

색상:
- 한 가지 색상만 과하게 쓰지 말 것
- 보라색/남색 그라데이션 중심의 AI 툴 느낌은 피할 것
- 흰색/회색 기반에 포인트 컬러 1-2개
- 커머스/작업 도구에 어울리는 신뢰감 있는 색상

타이포그래피:
- 화면 제목은 명확하게
- 폼 라벨은 읽기 쉽게
- 캔버스 안 상세페이지 문구는 모바일에서 읽기 좋은 크기
- 버튼 안 텍스트가 넘치지 않게

컴포넌트:
- shadcn/ui 기반으로 만들기
- Button, Card, Input, Textarea, Select, Tabs, Badge, Separator 사용 가능
- 아이콘은 lucide-react 사용
- 드래그 핸들, 숨김, 재생성, 다운로드, 저장 등은 아이콘 버튼 사용

레이아웃:
- 관리자/대시보드 화면은 정보 밀도 있게
- 편집기 화면은 3열 구조 가능
- 모바일 상세페이지 캔버스는 고정 폭 미리보기로 표시
- 작은 화면에서도 내용이 겹치지 않게

금지:
- 마케팅 랜딩페이지처럼 과한 hero 만들지 말 것
- 장식용 gradient orb, bokeh, 추상 배경 사용하지 말 것
- 기능 설명 텍스트를 화면 곳곳에 과하게 넣지 말 것
- 카드 안에 카드를 계속 중첩하지 말 것
- 피그마/포토샵 같은 자유 편집 UI로 만들지 말 것
```

## Claude Design에 기대하는 산출물

```txt
아래 산출물을 만들어줘.

1. 전체 앱 IA와 화면 흐름
2. 핵심 화면 UI 초안
3. 상세페이지 편집기 화면을 가장 구체적으로 설계
4. 각 화면의 주요 컴포넌트 구조
5. shadcn/ui로 구현하기 좋은 컴포넌트 단위 제안
6. 사용자가 실제로 클릭하게 될 primary action 정리
7. 개발자가 바로 구현하기 위한 파일/컴포넌트 분리 제안

가능하면 현재 repo 구조를 보고, Next.js App Router 기준으로 어떤 route와 component를 만들면 좋을지도 제안해줘.
```

## 추가 요청 프롬프트: 상세페이지 편집기만 다시 고도화

```txt
위 서비스에서 가장 중요한 화면은 상세페이지 편집기야.

편집기 화면만 다시 더 고도화해서 디자인해줘.

목표:
- 셀러가 AI가 만든 상세페이지를 빠르게 검토한다.
- 마음에 안 드는 섹션만 수정한다.
- 섹션 순서를 바꾼다.
- 플랫폼별 export를 수행한다.

반드시 포함:
- 모바일 상세페이지 캔버스
- 섹션 순서 리스트
- 선택 섹션 편집 패널
- AI 재생성 버튼
- 카피 후보 선택 UI
```
