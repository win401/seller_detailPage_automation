# Claude Design Prompt

## 사용 방법

Claude Design에 아래 GitHub repo를 연결한 뒤, 이 프롬프트를 입력합니다.

```txt
https://github.com/win401/seller_detailPage_automation.git
```

## 프롬프트

```txt
너는 웹 애플리케이션 UI/UX 디자이너이자 프론트엔드 설계자야.

연결된 GitHub repo를 참고해서 Next.js + TypeScript + Tailwind CSS + shadcn/ui 구조에 맞는 UI 초안을 만들어줘.

서비스 개요:
이 서비스는 커머스 셀러가 상품 정보와 이미지를 입력하면 AI가 상세페이지 초안을 만들고, 사용자가 데스크톱에서 모바일 상세페이지 캔버스를 보며 블록 단위로 수정한 뒤 플랫폼 업로드용 이미지 ZIP을 다운로드하는 웹 애플리케이션이야.

중요:
- 사용자는 PC/노트북에서 작업한다.
- 결과물 미리보기는 모바일 상세페이지 형태의 긴 세로 캔버스다.
- 피그마/캔바 같은 자유 디자인 툴이 아니다.
- 섹션 블록 단위로 편집하는 AI 상세페이지 편집기다.

기술 전제:
- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- lucide-react
- dnd-kit
- Supabase
- Vercel AI SDK
- JSZip

디자인할 화면:
1. 로그인/회원가입
2. 프로젝트 대시보드
3. 새 상세페이지 생성
4. 상세페이지 편집기
5. 스타일 세트 관리
6. 관리자 화면

전체 디자인 방향:
- 실무용 웹 앱처럼 차분하고 명확하게
- 과한 랜딩페이지 느낌 금지
- 장식보다 작업 흐름을 우선
- 정보가 많은 화면도 정돈된 밀도로 구성
- 카드 중첩을 과하게 사용하지 말 것
- 아이콘은 lucide-react 기준으로 제안
```

## 화면별 요구사항

### 1. 로그인/회원가입

```txt
필수 요소:
- 서비스명
- 이메일 입력
- 비밀번호 입력
- 로그인 버튼
- 회원가입 전환
- 데모 계정 진입 버튼

방향:
- 업무 도구에 들어가는 첫 화면처럼 단정하게 구성
- 과한 일러스트나 추상 배경은 사용하지 않음
```

### 2. 프로젝트 대시보드

```txt
필수 요소:
- 상단 네비게이션
- 새 상세페이지 만들기 버튼
- 프로젝트 검색
- 프로젝트 리스트
- 상품명, 카테고리, 플랫폼, 수정일 표시
- 스타일 세트 바로가기

방향:
- 프로젝트가 늘어나도 관리하기 쉬운 리스트/테이블 중심
- 다음 행동이 명확해야 함
```

### 3. 새 상세페이지 생성

```txt
필수 요소:
- 상품명
- 카테고리
- 핵심 키워드
- 타깃 고객
- 상품 이미지 업로드
- 톤앤매너 선택
- 디자인 무드 선택
- 강조 포인트 체크박스
- 플랫폼 선택
- 스타일 세트 선택
- AI 생성 버튼

UI 방향:
- 모든 항목을 텍스트 입력으로 만들지 말 것
- 선택형 UI, 체크박스, 토글, 칩을 적극 사용
- 이미지 최적화 상태를 표시
- 입력 부담이 적어 보이게 섹션을 나눔
```

### 4. 상세페이지 편집기

```txt
가장 중요한 화면이므로 가장 구체적으로 설계해줘.

핵심 구조:
- 데스크톱 작업 화면
- 모바일 상세페이지 캔버스
- 섹션 목록
- 선택 섹션 편집 패널
- 상단 작업 바

모바일 캔버스:
- 긴 세로형 상세페이지
- 13개 섹션 표시
- 선택된 섹션 하이라이트
- 실제 export 결과와 유사한 비율

13개 섹션:
1. Intro
2. One Line Selling Point
3. Problem
4. Solution
5. Key Benefit 1
6. Key Benefit 2
7. Key Benefit 3
8. Detail Point
9. Use Scene
10. Recommended For
11. Trust Point
12. FAQ
13. CTA

편집 기능:
- 문구 수정
- 이미지 교체
- 섹션 숨김/복구
- 섹션 순서 변경
- 카피 후보 선택
- 특정 섹션 다시 생성

상단 작업:
- 저장
- 미리보기
- 플랫폼 선택
- 전체 PNG 다운로드
- 슬라이싱 ZIP 다운로드

금지:
- 자유 좌표 편집
- 임의 텍스트 박스 생성
- 레이어 패널
- 자유 드로잉 도구
```

### 5. 스타일 세트 관리

```txt
필수 요소:
- 스타일 세트 목록

- 기본 디자인 무드
- 기본 톤앤매너
- 대표 색상
- 보조 색상
- 기본 플랫폼
- 섹션 표시/숨김 기본값
- 브랜드 메모

방향:
- 반복 작업을 줄여주는 설정 화면처럼 구성
- 색상은 swatch UI 사용
- 섹션 표시 여부는 토글 리스트 사용
```

### 6. 관리자 화면

```txt
필수 요소:
- 전체 사용자 수
- 전체 프로젝트 수
- AI 생성 횟수
- ZIP 다운로드 횟수
- 최근 프로젝트 메타데이터
- 최근 이벤트 목록

방향:
- 기본 운영 확인용 화면
- 개별 상품 원문이나 민감한 입력값을 크게 노출하지 않음
- 단순하고 읽기 쉬운 대시보드 형태
```
