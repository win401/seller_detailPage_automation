# Demo Script

Last updated: 2026-07-10

A ~5분 발표용 흐름입니다. 실제 AI API 키가 없거나 quota 오류가 나도 mock
fallback으로 전체 흐름이 끊기지 않고 통과합니다 — 데모 전에 반드시
재확인할 필요는 없지만, 가능하면 `OPENAI_API_KEY` quota를 미리 확인해서
"실제 AI 응답"으로 시연하는 쪽을 우선하세요.

## 0. 준비

- `npm run dev` 실행, 로그인 상태 확인 (데모 계정 또는 팀 테스트 계정).
- 발표 중 새로고침 실패에 대비해 미리 프로젝트 하나를 생성해두는 것을 권장합니다.

## 1. 대시보드 (30초)

- 로그인 후 대시보드에서 기존 프로젝트 목록을 보여줍니다.
- "프로젝트가 하나도 없으면 이렇게 빈 상태가 뜹니다" — 처음 쓰는 사용자 경험도 짧게 언급.

## 2. 새 프로젝트 생성 (1.5분)

- `새 상세페이지 만들기` 진입. 상품명/카테고리/키워드 등은 샘플 데이터로 미리 채워져 있습니다.
- 강조 포인트, 톤앤매너, 디자인 무드(미니멀/내추럴/프리미엄/컬러풀) 중 하나를 눌러 바꿔봅니다 — 무드에 따라 나중에 캔버스 이미지 톤이 달라짐을 강조 포인트로 씁니다.
- 상품 이미지 업로드 → 클라이언트에서 자동 최적화(용량 표시)되는 것을 보여줍니다.
- 레퍼런스 이미지도 업로드해봅니다 (분위기 참고용, 실제 상품 형태는 바뀌지 않음을 설명).
- `에이전트로 상세페이지 시안 생성` 클릭 → 분석 → 기획 → 제작 → 검수 4단계 진행 상태를 보여줍니다.

## 3. 에디터 (2.5분)

- 좌측 섹션 목록: 13개 섹션, 드래그로 순서를 바꿔봅니다 (그립 아이콘을 드래그).
- 섹션 하나를 선택해 우측 패널에서:
  - 본문 직접 수정
  - "카피 후보" 중 하나를 클릭해 헤드라인 교체
  - "레퍼런스 이미지 적용" 또는 "Pinterest 스타일 레퍼런스" 중 하나 선택 — 캔버스에 바로 반영되는 하이라이트 모션 확인
- 캔버스 확대/축소, Space+드래그 이동을 짧게 보여줍니다.
- 우측 하단 AI 도우미(기획자 에이전트) 버튼 클릭 → 모프 애니메이션으로 패널이 열림.
  - 예시 칩(예: "전체 톤을 더 프리미엄하게") 선택 후 "재기획 시안 만들기".
  - 적용 전/후 비교 카드가 뜨면 "새 시안 적용" 또는 "취소".
- Ctrl+Z / Ctrl+Shift+Z로 되돌리기/다시하기를 보여줍니다.
- 섹션 편집 패널의 "레이아웃"(이미지 위치 3x3 그리드, 채우기, 높이)과 "여백 & 텍스트 크기" 프리셋을 눌러 캔버스가 바로 바뀌는 것을 보여줍니다 — 자유 좌표가 아닌 프리셋이라는 점을 강조(블록 기반 편집 유지).
- 좌측 하단 "스타일 세트 적용"에서 세트를 골라 "전체 섹션에 레이아웃 적용"을 눌러 한 번에 톤을 바꿔봅니다. `/styles`에서 스타일 세트를 새로 만들거나 수정할 수 있다는 점도 언급.

## 4. 저장 & 내보내기 (1분)

- 상단 `저장` 클릭 → 저장 상태 뱃지 확인.
- `ZIP 다운로드` 클릭 → 플랫폼 폭 기준으로 2000px 단위 슬라이싱된 PNG들이 ZIP으로 묶여 다운로드되는 것을 확인.
- 대시보드로 돌아가 방금 저장한 프로젝트가 목록에 뜨는 것으로 마무리.

## 발표 중 자주 나올 수 있는 질문

- **"실제 AI가 만든 건가요?"** — API 키/quota가 정상이면 실제 OpenAI 응답이고, 실패 시에도 동일한 UX로 mock 초안이 즉시 나오도록 설계되어 있어 데모가 끊기지 않습니다. 에디터 좌측 하단 "에이전트 워크플로우" 패널에서 각 단계가 `Mock`인지 실제 응답인지 확인할 수 있습니다.
- **"경쟁사 페이지는 실제로 크롤링하나요?"** — 아니요, MVP 범위에서는 URL/메모만 참고 정보로 저장하고 자동 크롤링은 하지 않습니다.
- **"이미지도 AI가 새로 그리나요?"** — 섹션별 "AI로 이미지 생성" 버튼은 Gemini 2.5 Flash Image로 실제 생성 요청을 보냅니다. 나머지는 업로드한 상품/레퍼런스 이미지 또는 무드별 mock 레퍼런스 중에서 고르는 방식입니다.
