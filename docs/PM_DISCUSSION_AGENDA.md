# PM Discussion Agenda

## Purpose

이 문서는 상세페이지 AI 제작 프로그램의 기획 검토를 위해 PM/실제 셀러에게 전달할 논의 문서입니다.

현재 목표는 2026년 7월 19일까지 포트폴리오급 MVP를 완성하는 것입니다.

PM에게 확인받고 싶은 핵심은 다음입니다.

- 실제 셀러가 가장 필요로 하는 기능이 맞는지
- 상세페이지 제작 흐름이 실무와 맞는지
- 플랫폼 업로드 방식과 이미지 규격이 현실적인지
- 입력 폼이 셀러에게 부담스럽지 않은지
- 스타일 세트/템플릿 기능이 실제 반복 작업을 줄여주는지
- 관리자 대시보드와 사용 데이터 분석이 사업화 관점에서 의미 있는지

## Product Summary

이 서비스는 초보 셀러가 상품 정보와 이미지를 입력하면 AI가 상세페이지 문구, 섹션 구성, 디자인 초안을 자동 생성해주는 상세페이지 제작 도구입니다.

사용자는 PC/노트북에서 서비스를 사용합니다.

결과물은 모바일 쇼핑 상세페이지에 맞는 긴 세로형 이미지입니다.

핵심 플로우:

1. 셀러가 상품 정보와 이미지를 입력합니다.
2. 톤앤매너, 디자인 무드, 강조 포인트를 선택합니다.
3. AI가 13개 섹션 기반 상세페이지 초안을 생성합니다.
4. 사용자는 블록형 캔버스에서 문구, 이미지, 섹션 순서를 수정합니다.
5. 플랫폼 규격에 맞춰 이미지를 슬라이싱합니다.
6. ZIP 파일로 다운로드해 쇼핑몰 관리자에 업로드합니다.

## PM에게 확인할 핵심 질문

## 1. 실제 상세페이지 제작 흐름

현재 가정:

셀러는 상품 정보와 이미지를 준비한 뒤, 상세페이지 문구와 디자인 구성을 만들고, 최종 이미지를 잘라 쇼핑몰에 업로드합니다.

확인 질문:

- 실제 셀러는 상세페이지를 보통 어떤 순서로 제작하나요?
- 상품 사진, 카피, 디자인 중 가장 시간이 많이 걸리는 부분은 무엇인가요?
- 상세페이지 제작 시 가장 자주 막히는 지점은 무엇인가요?
- 기존에는 포토샵, 피그마, 미리캔버스, 캔바 중 어떤 도구를 많이 쓰나요?
- 외주를 맡길 때 가장 불만족스러운 부분은 무엇인가요?

## 2. 데모 상품 카테고리

현재 후보:

- 린넨 셔츠
- 프리미엄 텀블러
- 감성 디퓨저
- 뷰티 세럼

확인 질문:

- 발표/시연에 가장 적합한 상품 카테고리는 무엇인가요?
- 셀러 입장에서 상세페이지 제작 니즈가 가장 큰 카테고리는 무엇인가요?
- 이미지와 카피가 모두 중요해서 데모 효과가 좋은 상품은 무엇인가요?
- 쿠팡/스마트스토어/에이블리/지그재그 중 어느 플랫폼 기준 데모가 가장 설득력 있나요?

## 3. 13개 섹션 구조

현재 13개 섹션:

1. 인트로
2. 한 줄 셀링포인트
3. 고객 불편
4. 해결 제안
5. 핵심 장점 1
6. 핵심 장점 2
7. 핵심 장점 3
8. 상세 정보
9. 사용 장면
10. 추천 대상
11. 신뢰 포인트
12. FAQ
13. 구매 유도

확인 질문:

- 실제 상세페이지에 이 13개 섹션이 모두 필요한가요?
- 빠져야 하거나 추가되어야 할 섹션이 있나요?
- 카테고리별로 섹션 순서가 달라져야 하나요?
- 구매 전환에 가장 중요한 섹션은 무엇인가요?
- FAQ는 실제 상세페이지에서 중요한가요?
- "고객 불편 -> 해결 제안" 구조가 모든 상품에 적합한가요?

- 상품 이미지
- 톤앤매너

확인 질문:

- 입력하면 좋지만 선택으로 두어야 하는 정보는 무엇인가요?
- 가격, 소재, 사이즈, 구성품, 배송 안내는 필수인가요?

- 셀러 입장에서 입력 폼이 길어져도 괜찮은 기준은 어디까지인가요?

## 5. AI 카피 생성

현재 방향:

AI가 자유 문장이 아니라 13개 섹션 JSON을 생성합니다.

출력 규칙:

- 과장 표현 금지
- 상품 정보에 없는 효능/인증/수치 생성 금지
- 모바일에서 읽기 쉬운 짧은 문장
- 섹션별 대체 카피 후보 제공

확인 질문:

- AI가 생성하면 위험한 표현이나 금지해야 할 문구가 있나요?
- 카테고리별로 특히 조심해야 하는 표현이 있나요?
- 셀러가 가장 많이 원하는 카피 톤은 무엇인가요?
- "감성형", "정보형", "공구형", "프리미엄형" 중 실제로 자주 쓰는 톤은 무엇인가요?
- 섹션별 대체 카피 후보가 실제로 도움이 될까요?
- 특정 섹션만 다시 생성하는 기능이 필요한가요?

- "Pinterest 스타일"보다 내부 무드 프리셋 방식이 현실적인가요?

## 7. 블록형 편집기

현재 방향:

가능한 편집:

- 섹션 숨김/복구

불가능한 편집:

- 텍스트 박스 자유 배치
- 이미지 자유 배치
- 레이어 편집
- 세밀한 리사이즈

확인 질문:

- 셀러에게 자유 편집보다 블록형 편집이 더 적합한가요?
- 섹션 순서 변경은 실제로 필요한가요?
- 섹션 숨김/복구 기능이 필요할까요?
- 이미지 교체만으로 충분한가요, 간단한 크롭도 필요할까요?
- 피그마식 자유 편집을 제공하지 않는 것이 오히려 장점으로 보이나요?

현재 방향:

1차로 보는 데이터:

- 전체 가입자 수
- 전체 프로젝트 수
- AI 생성 횟수
- ZIP 다운로드 횟수
- 인기 상품 카테고리
- 인기 디자인 무드
- 인기 톤앤매너

데이터 원칙:

확인 질문:

- 데이터 리포트가 있다면 어떤 제목/형태가 가장 매력적일까요?
- 개별 상품 정보가 아닌 집계 데이터라면 셀러가 불편함을 느끼지 않을까요?
- 관리자 대시보드에서 꼭 봐야 할 운영 지표 TOP 5는 무엇인가요?
