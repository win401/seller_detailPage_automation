# AGENTS

## Project Role

This project is a two-week mini-project workspace for a Coupang and Smart Store seller detail page automation tool.

## Operating Rules

- Keep this project focused on seller detail page automation.
- Do not mix previous local tourism, traditional market review dashboard, or hackathon ideas unless the user explicitly asks.
- Prioritize a working MVP over broad platform integrations.
- Use Korean copy for user-facing product text unless the user asks otherwise.
- Make design choices friendly for beginner sellers and small business owners.

## Current Direction

The product should help sellers move from raw product information and photos to a usable sales detail page draft.

Core sequence:

1. Product information input
2. Image upload
3. AI-generated sales copy
4. AI/design-generated layout
5. Editable preview
6. Export/download

## Preferred MVP Stack

- Next.js + TypeScript
- Tailwind CSS + shadcn/ui
- Claude API or OpenAI API for text generation
- Claude Design as a design creation workflow
- html-to-image or Playwright for export
